SPLITEASE - PUBLIC SETUP & CONFIGURATION GUIDE
==============================================

Welcome to SplitEase! Follow these steps to set up, configure, and run SplitEase locally on your machine.

----------------------------------------------------------------------
1. PREREQUISITES
----------------------------------------------------------------------
- Flutter SDK 3.22+ (run `flutter doctor` to confirm your installation)
- Node.js 20+ and Firebase CLI (`npm install -g firebase-tools`)
- A Firebase account (https://console.firebase.google.com/)
- Android Studio / Xcode for device emulators

----------------------------------------------------------------------
2. CLONE & INSTALL DEPENDENCIES
----------------------------------------------------------------------
1. Clone the repository:
     git clone https://github.com/your-username/splitease.git
     cd splitease

2. Fetch Flutter package dependencies:
     flutter pub get

3. Install Cloud Function dependencies:
     cd functions
     npm install
     cd ..

----------------------------------------------------------------------
3. FIREBASE SETUP
----------------------------------------------------------------------
1. Create a new Firebase project at https://console.firebase.google.com/
2. Enable Authentication:
   - Go to Build -> Authentication -> Sign-in method.
   - Enable "Email/Password" and "Google".
3. Create a Cloud Firestore database in production or test mode.
4. Connect Firebase to your local project using FlutterFire CLI:
     dart pub global activate flutterfire_cli
     flutterfire configure
   (This automatically generates `lib/firebase_options.dart` and links your app).

----------------------------------------------------------------------
4. GOOGLE SIGN-IN SETUP (ANDROID)
----------------------------------------------------------------------
1. Get your local debug SHA-1 key:
   - Windows:
     keytool -list -v -keystore %USERPROFILE%\.android\debug.keystore -alias androiddebugkey -storepass android -keypass android
   - macOS/Linux:
     keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
2. Copy the `SHA1:` fingerprint string.
3. In Firebase Console -> Project Settings -> Your Android App -> Add Fingerprint.
4. Re-run `flutterfire configure` to refresh `lib/firebase_options.dart`.

----------------------------------------------------------------------
5. CLOUD FUNCTIONS & FIRESTORE RULES DEPLOYMENT
----------------------------------------------------------------------
1. Upgrade Firebase project to the Blaze plan (includes 2 million free invocations/month).
2. Deploy Security Rules and Cloud Functions:
     firebase deploy --only firestore:rules,functions

----------------------------------------------------------------------
6. RUN & TEST THE APP
----------------------------------------------------------------------
1. Run automated unit tests:
     flutter test
2. Launch app on an emulator or physical device:
     flutter run
